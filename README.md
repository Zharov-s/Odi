# Одиссея продлений

Кинематографичный рабочий дашборд продлений по направлениям «Отель» и «ФМС». Цель месяца отображается как маршрут к Итаке, а фактический прогресс — как положение двух кораблей.

## Источник данных

Дашборд читает Google Sheets через публичный Google Visualization API и обновляется каждые 5 минут:

https://docs.google.com/spreadsheets/d/1p5J6hw_fNIT99BXM9UDPEi5cTbDiSwudalQCWgAI4I8/edit

Используются вкладки:

- `Цель август` — общие показатели и цели по направлениям;
- `Отель` — персональные результаты направления;
- `ФМС` — персональные результаты направления;
- `Личные допродажи` — топ-5 МПП по сумме допродаж.

Для автоматического обновления у таблицы должен сохраняться доступ «Все, у кого есть ссылка — читатель».

## Запуск

Требуется Node.js 22.13 или новее.

```bash
npm install
npm run dev
```

Проверка production-сборки:

```bash
npm run build
npm test
```

## Расчёты

- проценты, цели, остаток и дневная цель берутся из вкладки `Цель август`;
- прогноз рассчитывается по среднему темпу за прошедшие рабочие дни текущего месяца;
- рабочими днями считаются понедельник–пятница в часовом поясе `Europe/Moscow`;
- топ допродаж агрегируется по ФИО и сортируется по общей сумме;
- если Google Sheets временно недоступен, интерфейс показывает последние резервные значения и предлагает повторить загрузку.
